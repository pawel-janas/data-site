# data.paweljanas.com

Static documentation site for Pawel Janas's datasets. Served by GitHub Pages
from the root of the `main` branch, at https://data.paweljanas.com (see `CNAME`).

These files are generated by `build.py` from `catalog.json` in the source project
(kept separately). To update: edit `catalog.json`, run `python3 build.py`, and upload
the contents of `public/` here, replacing the old files.
